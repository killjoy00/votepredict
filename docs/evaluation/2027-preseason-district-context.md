# 2027 district election context (Nov 27, 2026)

The SOS certified general election results on November 19 ([announcement](https://sos.mn.gov/about-the-office/news-room/state-canvassing-board-certifies-results-of-the-2026-general-election/), [certificate index, document 20263751](https://officialdocuments.sos.mn.gov/Document/Details/160996)). The [machine-readable results index](https://electionresults.sos.mn.gov/Select/MediaFiles/Index?ersElectionId=201) still labels downloadable files unofficial; do not infer that every downloaded tally is certified, particularly for recount districts. [Recount index](https://sos.mn.gov/elections-voting/election-results/2026/2026-general-election-results/2026-state-recounts/). The Senate text export was accessible in browser review; House text export failed browser decoding. Existing bounded source fetch handles UTF-8 and Windows-1252 and was successfully used November 26 for all 201 districts.

This keyless, PR-only, two-request public probe reuses the existing official district parser and frozen projected roster. Each seat requires complete precinct counts, unique candidate order, one office, exact ballot-name/party agreement and summed votes equal to official total. Compute share from integer votes and strongest *named* opponent margin; write-ins count in the denominator but are not an opponent or a named candidate. Uncontested races have null named-opponent margin rather than a fabricated landslide margin. Hold House 32A, Senate 4 and Senate 33 for separate exact recount tally review even if the projected identity was accepted. Output report-level source hash, byte count, observation date, and per-seat review; never expose voter-level data. No canonical writes, no database access, no production archive slot, no schedule, no Vercel, no model changes. Original bytes not retained in this probe; production intake remains a separate reviewed, bounded source-retention step. If a tally changes or identity differs, hold it; do not modify the projected roster. These are electoral context observations, not evidence that a member supports any specific bill.
