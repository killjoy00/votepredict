## Why this matters

The original official Minnesota Senate [2021 Miscellaneous Journal Index PDF](https://www.senate.mn/journals/2021-2022/2021misc.pdf) includes a **Rule #12.10** publication entry section, followed by an index for Rule #14.1. The file's 2021-based title does NOT establish that all indexed journal references were published in calendar 2021: **SF2909, printed page 5098, is independently documented by the Minnesota Revisor as February 24, 2022.** Unlike searching the web for isolated bills, a clearly delimited 2021 Journal index section may offer a more systematic **list of published Rule 12.10 committee-vote report references** by SF number and printed Journal page.

This is NOT an exhaustive census of all 2021 Senate committee motions or member votes: Rule12.10 committee divisions are included in the Journal selectively after three members requested a roll and a printed committee report. Other unrequested committee motions, voice votes, amendments, withdrawn or failed motions and separate 2021 official print-only committee minutes are not enumerated by this shortcut. Candidate SF number/printed page references are themselves *index lines*, not original named member-vote paragraphs or evidence of a new missing VotePredict record. No new statewide denominator or source parity claim is authorized.

## Exact source-only acquisition

The [index section inspector](../../src/evidence/senate-2021-original-journal-misc-rule1210-index-source.ts) requires an actual MISCELLANEOUS INDEX title, exactly one Rule #12.10 section header, and a nearby bounded subsequent Rule #14.1 header. It conservatively extracts dotted-leader SF number / printed-Journal-page *candidate* lines from the intervening text. It rejects a duplicate Rule12.10 heading, a wrong source, absent delimiters, duplicate/out-of-range references, and unreasonably small/large sections, and always preserves a possible-extraction-misses warning. The captured bounded source window is for human review only; counts, even if all lines are found, never become a statewide committee recorded-vote denominator.

The [one-time original PDF source action](../../.github/workflows/senate-2021-misc-journal-rule1210-index-original.yml) fetches exactly https://www.senate.mn/journals/2021-2022/2021misc.pdf (no redirects, MIME checks, streamed 18 MB cap, PDF magic), extracts and hashes original binary and embedded text, and attempts the strict source section parse. It writes original file size/SHA256, original text SHA256, candidate bill-page references, bounded passage SHA and limited public *index-only* excerpt to one original temporary workflow artifact. **A failed parser must remain recorded as failed**, but the temporary artifact preserves bounded diagnostic evidence to fix the actual PDF layout without substituting made-up index entries.
