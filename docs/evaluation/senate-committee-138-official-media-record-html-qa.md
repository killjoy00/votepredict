# Issue #864 — official media record HTML is not a verified Senate committee recording

Source runs #38079233118 and #38079795850 established that 138 **specific** LRL /media/file?mtgid= archive record URLs occur inside the 2022–25 exact committee hearing-date sections for 141 indexed meetings with no linked Minutes PDFs. All 138 responded HTTP 200 to a HEAD request with a text/html content-type. Neither an official archive record URL nor HTTP 200 establishes **audio/video playback**, that a committee meeting rather than a generic file is associated with the record, or named YEA/NAY choices.

A bounded source-only one-time workflow at .github/workflows/senate-committee-138-media-record-html.yml performs safe HTTP GET only for expected **text/html** metadata pages, independently source-hash-pinned in the prior verified 138-href artifact outputs. It explicitly rejects non-HTML content before reading any bytes: no audio, video, stream, transcript or downloadable media is fetched or stored. Redirects are not followed. Page response bytes capped at 600 KiB, two parallel requests per year, and a 30-second timeout per request. Only HTML SHA-256, page-title SHA-256, record ID, HTML byte length and conservative counts of explicit audio/video/source/iframe markup, download/transcript/media-labeled anchors, apparent missing-record text and related metadata go into the audit. There is no browser script execution and source HTML is untrusted.

**Classification policy:** a generic Watch/Listen navigation link does not constitute a playable recording; even an HTML audio or video tag is a *candidate* player reference, not playback proof. Any HTTP non-200, non-HTML content, redirect or parser failure remains an unresolved source status; no missing individual vote is fabricated. Public archive record pages that explicitly declare 'file not found' are anomalous even if HTTP 200. Real-media accessibility and speaker/committee identity must be separately corroborated before spoken roll votes can be reconstructed.

This does **not** inspect the 2021 print-only Senate committee minutes, reconcile the 2022 print/electronic disagreement, or repair the private evidence database. No production database, serving/model/prediction/retraining/scheduler/2027 changes and no public office contact. Keep issue #864 open.
