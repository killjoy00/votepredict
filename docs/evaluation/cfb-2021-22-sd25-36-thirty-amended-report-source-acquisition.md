The PR-only [official-source job](../../.github/workflows/cfb-2021-22-served-sd25-36-30-amendments.yml) re-requests original CFB candidate reports-tab responses for the 10 applicable registrations, requires exact original API JSON SHA and unique observed amendment keys, then requests **the actual original PDF bytes** for every amended version. It audits official report source URL, raw binary SHA/size, independently matched Senate principal campaign committee registration, office, original reporting period, printed office district (**the same person's pre-redistricting verified Senate service district is allowed**, not a nearby district), Board receipt not preceding original report receipt, and binary identity distinct from the original parent. All amended versions must have unique bytes **except the exact SHA-, size-, parent-, receipt- and reference-pinned Hoffman alias below**. Earlier and later version receipt dates must not reverse. An unexpected duplicate anywhere else fails source verification. These are safeguards for *amended-version source PDFs*, **not a count of legally owed additional filings**.

Any atypical PDF (such as the separate, explicitly held 2021 YE Aric Putnam amendment #1 in the **other** SD14–24 cohort) must remain unverified until its own independent source identity is established. We must not apply a broad parser relaxation, manufacture a filing or public-by date, or fail to preserve true source-only PDFs that need independent documentary classification. The artifact retains only report-version IDs, official Senate-serving people, PDF hashes/byte sizes, reporting and received dates, first-page verification status and source times, never full PDF text, donors, individual transactions, addresses, votes or other people's names.

The independent CFB 2022 calendar establishes source original C/E statutory due dates **2022-07-25** and **2022-10-31**, 2021 YE **2022-01-31**, and 2022 YE **2023-01-31**. The original report period and deadline belong to the parent report; an amendment's Board receipt date is a separate source fact. Conservative later date-only release floors **do not establish when amended data actually first became public**. Therefore no amendment version is eligible to enter a historical prediction from this source proof alone.
