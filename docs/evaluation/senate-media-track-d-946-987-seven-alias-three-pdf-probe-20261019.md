The older Reformer research proved original `/briefs/` bodies for 13 original publisher URL paths over 2021–2025. It also identified **seven unverified historic /briefs/ vs /YYYY/MM/DD/ same-slug relationships**, which cannot be assumed to be a single archived article. The earlier four-pair audit found no historically authenticated exact dated-path variants; three additional historically verified brief pages added three candidate dated-path URL hypotheses. The new audit specifically queries **only those seven exact preexisting dated counterpart URLs**, not an unrestricted publisher crawl.

For MPR, earlier source studies found independently verifiable 2023 Kunesh printed short speaker cues by a Feb. 10 2023 capture, but not necessarily at the Feb. 7 broadcast. Two currently served 2025 APM/3Play PDFs for Susan Pha and Julia Coleman were hashed but their historical original archival binaries remained unknown. This follow-up queries only **those three exact original PDF URL identities**, not a podcast/audio census.

## Fixed evidence-only procedure

The new `src/evaluation/senate-media-track-d-remaining-original-probe.ts` and `scripts/probe-senate-media-track-d-seven-alias-three-pdf-v6.ts` implement an audit with:

- **Seven** fixed Reformer dated-path hypotheses derived from the same pinned and SHA1/SHA256 original brief manifest validated by the earlier research-only capture. Original host, identical exact slug, checked publisher-displayed day, 2021–2025 archive scope, and previously authenticated /briefs/ source URL are required. The known brief remains a separate source identity.
- **Three** fixed exact APM CDN PDF original URLs, pinned to prior independent publisher-original PDF receipt SHA256s and known archived PDF availability. No new unreviewed transcript URL is permitted.
- **Ten exact CDX index queries maximum**, each bounded and strictly checking original full URL, old year window, authentic archive timestamp, MIME/status and indexed original SHA1. Up to **two** exact timestamped `id_` archive replays per original URL if a trustworthy index contains candidates, never a redirect, live publisher alternative or archive/robots bypass. This is a bounded selected index page and not an exhaustive historical archive census.
- If an HTML replay matches the CDX-indexed original SHA1, it is an authenticated body for that exact **dated** URL only. The full raw HTML SHA256 may be recorded as a public checksum. Both dated and brief original paths would then have authenticated historical bodies, but **no article-identity/duplicate conclusion is made** without a separate original text/byline/timing comparison. Mismatch remains quarantined and archive outages remain **UNKNOWN**.
- If an APM PDF replay is authentic, the verifier validates a PDF magic header, indexed raw-body SHA1 and raw SHA256. The body SHA256 is compared to the prior independently authenticated 2026-served PDF (and prior 2025 archive for Hauschild). Its exact historic observation time is recorded; however the embedded PDF creation date or the current HTTP Last-Modified cannot replace the independently observed historical archive clock. **No audio-verbatim or human approved transcript quote is inferred**.
- Each request is public-only with bounded length, manual no-redirect, exact approved original URLs and an archive-only single-host network surface. No article/PDF/audio bytes or full transcription are persisted or displayed, no private DB query is made, and zero source/forecast/model/collection modifications are possible from this code path.

The purpose is to narrow *which exact* historical source-original paths remain unverified, and whether any exact originally archived PDF can establish an earlier independently observed public copy. A positive original PDF does not establish the broadcaster's 2024/2025 transcript publication minute; a positive dated HTML does not establish article-family equivalence; neither certifies any full senator quote or Senate member's actual recorded vote.

The existing public MPR 2021/2024 audio MP3 hashes are **current publisher binaries**, not independently archived original MP3 bytes.

Both issues **remain open** for their final evidence/source-identity proof and any *separately approved* production historical ingestion.
