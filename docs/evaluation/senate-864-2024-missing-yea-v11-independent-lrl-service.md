## Independent government service index

The [Minnesota Legislative Reference Library's official State Senate service directory](https://www.lrl.mn.gov/legdb/senate_dir) is an independently maintained *public official* source with historical service-year/term and district listings. Its current public page is not a contemporaneous dated February 2024 Senate roll or a precise service/oath-day proof.

V11 reuses the exact **21 archived government Minutes/OCR original artifacts**, original 2024 ten-choice roll proof, three bounded source/event/choice SELECTs, V9 direct membership check, and V10 fixed 2023–24 Senate roster check. It adds **zero SQL queries**, no DB writes, and no change to the original parser. A new **pre-secret**, unprivileged job fetches the exact original LRL directory over HTTPS, enforces fixed URL / no redirects / HTML / 5-MiB byte cap, runs the independently tested original directory parser, and produces only its SHA-256 digest as a scoped Actions output. The protected job must **independently re-fetch identical LRL original bytes** and match that SHA before it may privately compare the original missing-YEA source spelling with directory names carrying **2024 year-overlapping Senate terms**.

The original source person name, source PDF URL, member IDs, and all names in the official directory stay inside the protected read-only job. The only new approved output is the bounded number of 2024-service directory candidate people, a static conservative resolver result (`matched | ambiguous | unmatched`) and one of five already reviewed static name-reconciliation reason codes. A separately **keyless** issue-receipt job revalidates exact field names, numeric bounds, original SHA check, `ROLLBACK`, the frozen one missing original YEA and **V10's exact still-unmatched existing roster**. Any mismatch, changed original directory, improper source, SQL drift, unexpected claims or unsafe output causes HOLD, not a fabricated match.

**Proof boundaries, even on a successful run:** a 2026-observed official directory with a 2024 service-year term is *not* independently certified February 2024 hearing-day service or source-PDF publication date, and an apparent official-name match does *not* establish the cause of historical missing member vote. Equally, no official-name match would not prove the original roll was invalid; OCR spelling, former names, transcription, original committee roster and officially timed service may still require investigation. Independently stored/deployed production DB binding remains unproven.
