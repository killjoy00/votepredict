# Issue #864 — independently reverify 15 OCR-derived candidate named Senate committee rolls

All originally low-text 2022–25 electronic Senate committee original PDF links were OCR recovered. The original-source parser returned **15 named roll-call candidates with 134 explicit named-choice tokens** across **10** scanned original PDFs: 2022 eight originals with eleven named-roll candidates and 99 named choice tokens; 2025 two originals with four named-roll candidates and 35 tokens. These are *proven parser observations*, not necessarily 15 unique original vote motions and not matched to an official senator roster or private member_vote rows.

The one-time [source integrity workflow](../../.github/workflows/senate-committee-15-named-roll-integrity.yml) re-fetches only those **ten immutable independently archived source-hash originals**. Its manifest is derived entirely from [final 152 source ledger](./source-proof/senate-committee-final-152-ocr-source-ledger.json) and [earlier 30 source ledger](./source-proof/senate-committee-30-scanned-ocr-source-ledger.json). Each original PDF is capped at 8 MiB and eight pages, with no HTTP redirects, and must reproduce its earlier actual original PDF SHA-256 and OCR text SHA-256.

The original v2 parser is rerun and each observation tested for exact previous roll/choice totals, mutually exclusive names within a roll, and YEA/NAY sums matching explicit source-name entries. Output persists original SHA hashes, vote-kind/context hashes, tally, and normalized choice identity hashes **but no source text, images, senator names, or PDF bytes**. If source SHA/content changes or any source member shows up as both YEA and NAY for a motion, fail closed.

**These are only mechanical integrity checks.** No individual senator historical membership roster check or human semantic action/motion distinction is claimed. Several motions can be identical tally and name sets; the original parser may merge some, so future source review must verify distinctness. Senator vote direction is not a final Senate passage stance. Hearing date is event/public-by, with same-day model cutoff excluded. No production DB, training, serving, scheduler, forecasts or 2027 work. Leave #864 open pending official print source and approved historical database reconciliation.
