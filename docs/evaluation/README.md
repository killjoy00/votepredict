# Evaluation and historical evidence records

Historical audit write-ups remain in this directory as immutable records of findings. Only audit modules with no operational or protected callers have been moved into research/evidence, research/scripts, and research/tests. The complete paths are indexed in docs/evidence-cleanup-inventory.md. Git history follows the file moves through git mv and git log --follow.

Neither findings nor data/evaluation artifacts are modified. No changes to model versions, forecast eligibility, evidence admissions, or production writes are implied by the archive.
