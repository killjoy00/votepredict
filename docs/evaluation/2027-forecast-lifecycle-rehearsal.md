It uses the actual introduction-stage runtime, the unchanged current-stage cohort seeder, and the real Quick runtime with a dated synthetic historical roll call and explicitly synthetic retained text observations in the same clean migrated local PostgreSQL database. This is a controlled local rehearsal, not an observed 2027 forecast, model-validation result, production activation, or forecast of the legislature. Actual 2027 bill text, amendments, official votes and final roster certification must still be verified as published. Frozen model weights, comparison gates, and the release pause are unchanged.
