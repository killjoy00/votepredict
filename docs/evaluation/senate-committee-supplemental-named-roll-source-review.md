# Issue #864 — separate, non-serving supplemental Senate named-vote source candidate parser

The original source review [#896](https://github.com/killjoy00/votepredict/pull/896), run #38078641464, successfully re-fetched and source-SHA-verified the **41** strongest original embedded-text Senate committee PDFs. Read-only, bounded human previews show that some contain explicit vote choices omitted by the existing strict v2 parser. This is not a comprehensive certification of missing actual votes.

The **separate** `src/evidence/senate-committee-supplemental-named-roll-review.ts` is NOT used by application ingestion, database, prediction or serving. It only proposes distinct candidate motion/vote segments when original text explicitly says, for example:
- a motion/request for roll call followed by **Ayes: Carlson, Westlin ... / Nays: Koran, Bahr ...** (including reversed source ordering, Yea/Nay, Yes/No);
- a roll-call vote followed by contiguous **Senator Carlson – Yea / Senator Koran – Nay** statements.

It never derives member choices from attendance lists, committee majority, aggregate counts, voice/unanimous actions or other unassigned outcomes. Source-reported numeric tallies are separately compared against the explicitly named source choices and given states **exact match**, **mismatch**, or **no supporting numeric tally**. Every result remains **`candidateNotVerifiedVote: true`** and no floor passage stance is inferred. Two senator names mapping to the same normalized identity but opposite choices invalidate the entire candidate. Numeric tally matching alone does not prove distinct motion, actual senator identity, exact passage semantics, hearing date or all named names were correctly recognized.

The one-time [four-year source-only workflow](../../.github/workflows/senate-committee-41-supplemental-named-choice-review.yml) reopens only the 41 exact source-pinned originals with original-PDF and extracted-text SHA verification and 3 MiB/30-page bounds, then produces metadata-only candidate choice identity hashes and counts. It retains at most three short temporary source QA snippets per original; no original PDFs, full transcripts, named people lists or private DB files are stored or committed.

**Do not automatically promote or ingest any supplemental candidate.** Additional original-text contextual review, disambiguation of repeated motions/amendments, independent original Senate membership by historical committee/date and separately authorized private-source reconciliation are prerequisites to any production correction. Committee voting is not Senate floor final-passage voting. 2021 Senate print and 2022 print/electronic discrepancies plus 141 no-Minutes-linked meetings remain open. No office contact, model, scheduler, forecast, serving, 2027 or production database mutation; keep #864 OPEN.
