# #864 finance Track A — acquire 26 original amendment-version CFB PDFs for actual senators

This is the next **source acquisition** step after merged [#1012](https://github.com/killjoy00/votepredict/pull/1012), [#1020](https://github.com/killjoy00/votepredict/pull/1020), [#1022](https://github.com/killjoy00/votepredict/pull/1022), and [#1025](https://github.com/killjoy00/votepredict/pull/1025).

## Exact source population and what we are checking

The existing original 396-response CFB reports-tab viewer source (2022 segment) contains **42 original-version** report references already independently authenticated from PDF binaries for **11 Minnesota senators verified to have actually served**, plus **26 separate amendment-version references** across those identical eleven committees. Breakdown of these new amendment targets: **10 for 2021 YE**, **12 for 2022 YE**, **2 for 2022 pre-primary C**, and **2 for 2022 pre-general E**.

The cohort selector requires both permanent original-report PSV proofs, both original-checkpoint SHA-256s, **42 unique original binary PDF hashes**, 11 verified actual-senator source registration identities, all exact original CFB reports-tab body hashes and the complete 396-response source PSV. No source without a corresponding independently authenticated original report, no never-served candidate, no guessed committee join, no unobserved original amendment key, and no missing index in a multi-amendment chain.

Each original CFB amendment-version PDF is requested by the exact uniquely observed official CFB viewer amendment index, and held unless the source PDF magic, content hash, source identity, first-page principal-campaign-committee registration and Senate office, original reporting interval, original or historically verified district label, and Board receipt date match the previously authenticated original. Each amended PDF must differ at the binary level from its original; successive amendments cannot silently reuse an earlier binary or reverse their Board-received order. This distinguishes **original PDF** from **amendment 1** and **amendment 2** rather than counting 26 HTML links as 26 PDFs.

**Important:** The CFB viewer's amendment-version index is original source evidence that the version is listed as an amendment; it is **not** independent visual verification of a checked paper-form “Amended” box. The parser does not assert such a checkbox. Amended report period/receipts are kept separate from original and amendment receipt dates. Conservative possible public-release not-before bounds are derived from the amended Board receipt and previously independently authenticated original report due date, **not evidence of actual historic public-by**. Missing/ambiguous sources fail closed.

The one-time [source workflow](../../.github/workflows/cfb-2021-22-served-26-amendment-originals.yml) reads only public original CFB documents; source PDFs, raw text, contributors, transaction detail, home addresses and never-served candidate names are not persisted. Success/failure is reported in a bounded metadata-only artifact; any unverified amendment or out-of-order revision causes failure and must be investigated from the original source without inventing a result. Tests cover true original parent hashes, 26 exact CFB original API revision keys, first-page registration/district/period, Board receipt and PDF nonidentity, chained amendments, redistricting and rejection of changed source proof.

## Still not established

This source cohort **does not** establish a statewide legally owed filing denominator, active committee lifecycle, nonfilers, that amendments changed any financial amount, that any specific donor/transaction appears in an amendment, historic public-by dates for earlier predictions, or database row completeness. Those all require separate original evidence. No production Neon/Vercel reads/writes, model/forecasts, ingestion, scheduler, or 2027 work. Issue [#864](https://github.com/killjoy00/votepredict/issues/864) stays **OPEN**.

## First-party original PDF outcome: one special document HOLD

Two independent acquisition observations both obtained the same **128,524-byte** official CFB viewer PDF (SHA-256 **7529ad0bf417548f1617d2bb2b74e5115855844df4a979fdbb6ad3e5e6420acf**) for **Aric Putnam's 2021 YE amendment index 1**, source reference **18430:21:pcc:YE:0:1**. The official reference and distinct PDF bytes exist, but this particular PDF has **no extracted Senate office/district, committee registration label, covered reporting period, Board receipt stamp, or normal principal campaign report title**. Its first-party text extraction is 1,836 characters; the missing identity is a real, repeatable source gap, not an HTTP error and not evidence of nonfiling.

Accordingly, **25 other amendment PDFs passed exact first-page identity and received-date checks**, but this document is **HELD** and not counted as a fully authenticated amended report. Aric Putnam's amendment index 2 has independently authenticated PDF bytes and dates, but the chain from version 1 to version 2 is not fully authenticated until this HOLD can be resolved. All date-only historical public-by claims remain null; neither original nor later version may be used for an earlier cutoff without new proof.

The new source gate distinguishes **26 original PDF bodies successfully retrieved** from **25 actual verified amended finance report forms plus 1 unresolved source PDF**. It may preserve that exact observed condition only when the held PDF binary SHA and byte count match two independent source acquisitions and the first-page absence of ordinary identity fields remains unchanged. An unrelated additional hold, changed PDF, source error, duplicate amendment binary, or unexplained revision conflict still fails closed. This is a **partial evidence result**, not a claim of 26/26 authentication.
