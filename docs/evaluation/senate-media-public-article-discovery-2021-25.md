## Deterministic URL discovery blind spots

The existing `minnesota-reformer-article-archive` seed requests Wayback original URLs beginning with `https://minnesotareformer.com/202` and cannot directly select `/briefs/` paths. Independently, `mpr-news-story-archive` requests `https://www.mprnews.org/story/202` and cannot directly select actual published first-party **`/episode/`** audio/interview pages, even when those pages contain explicitly named actual Minnesota senator transcripts. For this particular interview slug, the separate topical path-priority filter also returns **false**, so relaxing the prefix alone would still not select it. The separate collector topical URL-path filter may reject **additional** URLs even within a configured seed (see [shadow audit](senate-media-public-discovery-shadow-gaps.md)). These are **URL-gate findings only** and do not establish that an article is missing from the persisted private corpus, unavailable via an alias, or historically discoverable.
