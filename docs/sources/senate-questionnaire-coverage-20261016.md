# Minnesota Senate raw candidate questionnaires: 2026 publisher recovery, historical expansion and identity links

## Scope
This collector stores only literal original-publisher question/answer pairs, unchanged original source bodies and retrieval metadata. It neither judges statements nor determines legislative voting positions. The requested Oct. 16, 2026 pass targets **2026, 2025 special election, 2024 special election and 2022**. The existing 2020 source catalog remains unchanged for historical reference, but **2020 is excluded from the protected production replay**.

## MHP / Habitat 2026
The MHP public index explicitly enumerates Minnesota *Senate* respondent pages under `/2026_questionnaire/`. The existing 23 and five newly indexed Senate candidate pages are the only intended source pages. Individual page extraction requires real candidate identity, Senate district, and at least two printed ordered Q&As; empty publisher search results, House answers, blank submission forms and anti-bot pages are never substituted for published answers. Anonymous automated source access can legitimately fail with HTTP 403; those are reported without using credentials, proxies or access-control bypasses. Sources are not counted as captured unless their actual Q&As are stored.

## Additional 2022 and special-election sources
- **2022 Star Tribune Duluth Senate guide**: The publication explicitly says answers were **edited for length**. Raw captures are the *publisher-edited text as printed*, not full unedited candidate submissions. Only State Senate Districts 3/8 and named respondents; exclude State House, county candidates and explicit nonrespondents.
- **2024 Senate District 45 (MPR)**: Publisher guide describes a three-question survey, but no records are written unless all required question/answer text is actually machine-readable. Introductory candidate biography or embedded/interactive loading text is insufficient.
- **2025 Senate District 60 DFL special election**: Five original publicly linked candidate endorsement questionnaire PDFs. Attempt anonymous original file download using Google Drive's standard public-file endpoint. Only a genuine, text-selectable PDF with configured candidate name, district/endorsement context and 2+ legible ordered Q&As is eligible. Retain the **original complete PDF bytes, base64-encoded losslessly in `raw_content`**, and hash the exact original PDF bytes. Label `content_type=application/pdf;base64`; never misrepresent PDF as HTML. Sign-in requirements, non-PDF responses or image-only/unreadable source bodies are reported as unavailable, not bypassed.

## Person linkage
Reuse `legislators`, `memberships`, `membership_source_aliases` and the existing shared `resolveSenator` session/district/name resolver. A unique sitting senator can be joined; a challenger who has never served in that session remains unmatched, even when only one sitting senator represents the same district. November 2022 Senate candidates are compared with **2023–2024** service memberships (not 2021–2022); 2024 special-election questionnaires with **2023–2024**; 2025/2026 with **2025–2026**. The protected collector performs a bounded **null-only** reconciliation of existing questionnaire links, updates neither candidate answers nor other raw sources, and reports its match count.

All collection/identity writes use the existing protected default Neon project and existing GitHub Actions independently reviewed-main gate. Existing raw Q&A snapshots, duplicate history and published dates are immutable. No changes to serving forecasts, feature tables, model weights or prediction logic.
